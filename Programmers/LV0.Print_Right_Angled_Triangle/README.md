# Print Right-Angled Triangle

## 📌 Problem Description  
Given an integer `n`, print a right-angled isosceles triangle with height and base of length `n` using the `*` character.  
The first row contains 1 `*`, the second row contains 2 `*`, and so on until the `n`-th row contains `n` `*`.  

---

### **Constraints**  
- 1 ≤ n ≤ 10  

---

### **Example**  

**Input**  
```
3
```

**Output**  
```
*
**
***
```
