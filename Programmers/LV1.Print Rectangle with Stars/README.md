# Print Rectangle with Stars

### **Problem Link**  
[Programmers - 직사각형 별찍기](https://school.programmers.co.kr/learn/courses/30/lessons/12969)  

## 📌 Problem Description  
You are given two integers `n` and `m` as input.  
Using the `*` character, print a rectangle of width `n` and height `m`.  

---

### **Constraints**  
- 1 ≤ n, m ≤ 1000  

---

### **Example**  

**Input**  
```
5 3
```

**Output**  
```
*****
*****
*****
```
