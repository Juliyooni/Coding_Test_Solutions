# Conditional Sum or Difference

## 📌 Problem Description  
You are given two integers `a`, `b` and a boolean variable `flag`.  
- If `flag` is **true**, return `a + b`.  
- If `flag` is **false**, return `a - b`.  

---

### **Constraints**  
- -1000 ≤ a, b ≤ 1000  

---

### **Example**  

| a   | b  | flag  | result |
|-----|----|-------|--------|
| -4  | 7  | true  | 3      |
| -4  | 7  | false | -11    |

---

### **Example Explanation**  
- **Example 1**: flag = true → `a + b = -4 + 7 = 3`  
- **Example 2**: flag = false → `a - b = -4 - 7 = -11`
