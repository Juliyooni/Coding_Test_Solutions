# Multiple Check

## 📌 Problem Description  
Given two integers `num` and `n`, complete the function `solution(num, n)` such that:  
- If `num` is a multiple of `n`, return `1`.  
- Otherwise, return `0`.  

---

### **Constraints**  
- 2 ≤ num ≤ 100  
- 2 ≤ n ≤ 9  

---

### **Example**  

| num | n | result |
|-----|---|--------|
| 98  | 2 | 1      |
| 34  | 3 | 0      |

---

### **Example Explanation**  
- **Example 1**: 98 is a multiple of 2 → return 1  
- **Example 2**: 34 is not a multiple of 3 → return 0
